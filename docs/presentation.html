Project Presentation

CineMetrics

Modern Movie Rating Analytics & Performance Dashboard

Presenter: Sasikala Velpula

Stack: React 18 • Tailwind CSS • Recharts • Vite • GitHub Actions

Live Site: sasikalavelpula.github.io/Movie_Rating_Analytics-

Motivation

Problem Statement & Objectives

  • Scattered Data: Movie ratings and critical scores on platforms like IMDb and Rotten Tomatoes are siloed across individual film pages.
  • Lack of High-Level Insights: Difficult to quickly see score distributions, genre benchmark averages, or historical era trajectories.
  • Our Objective: Create a responsive, unified analytics dashboard with interactive charts, real-time filtering, and zero-friction CI/CD deployment.
Architecture

Technology Stack

Frontend UI & State

React 18 & Vite: Lightning-fast compilation, reactive component tree, and instant Hot Module Replacement.

Styling & Design

Tailwind CSS: Sleek dark cinema palette, custom glassmorphism, responsive breakpoints, and gold star badges.

Visual Analytics

Recharts: Declarative, responsive SVG charts with animated tooltips and customized gradients.

DevOps & Deployment

GitHub Actions & Pages: Automated build pipeline triggering on git push with instant live CDN deployment.

Visualizations

Interactive Charts (Recharts)

  • Rating Distribution (Bar Chart): Segments movie counts into score brackets (8.4-8.5, 8.6-8.7, 8.8-8.9, 9.0-9.1, 9.2+).
  • Average Rating by Genre (Horizontal Bar): Compares quality benchmarks across Drama, Sci-Fi, Crime, Action, Animation, and Adventure.
  • Decade Trends (Area Chart): Maps score evolution from 1970s classics to modern 2020s releases with smooth gradient fills.
User Experience

Filtering, Search & Exploration

  • Real-Time Search: Searches by movie title, director name, and genre keywords simultaneously.
  • Genre Pill Filters: Single-click filtering across Drama, Sci-Fi, Crime, Animation, and more.
  • Score Thresholds: Quick selection for 8.5+, 8.7+, and 9.0+ Masterpiece tiers.
  • View Modes: Dynamic switcher between visual Grid Cards and compact Table List.
  • Detail Modal: Full inspection dialog with synopsis, box office figures, runtime, and metascore.
DevOps

Continuous Deployment (CI/CD)

  • Git Repository: Source code version-controlled on GitHub.
  • Automated Pipeline: .github/workflows/deploy.yml runs on every push to main.
  • Zero Downtime: Automatically installs packages, compiles production bundle via Vite, and uploads to GitHub Pages.
  • Production Status: Live and verified with HTTP 200 OK status.
Conclusion

Future Enhancements & Wrap Up

  • Live TMDB API: Connect live streaming API for real-time synchronization of newly released movies.
  • Review Sentiment Analysis: NLP classification of user review comments.
  • User Bookmarks: Personal watchlists and user rating inputs.
